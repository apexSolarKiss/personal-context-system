This repository's workflow rules live in `AGENTS.md`. They apply to Claude Code the same as they apply to any other executor. For upstream-repository maintenance under ASK's operating surface, read the external grounding note as `AGENTS.md` requires; outside contributors and setup users are not expected to retrieve it. For project state, start from `README.md`.

When running the `SETUP-PROMPT.md` setup flow — from this checkout, a paste, or an upload — that prompt governs the interview, generation, delivery, and installation into a separate private destination. `AGENTS.md` never governs the generated private-system files; it continues to govern every mutation inside the scaffold checkout and every contribution intended for upstream, and it continues to forbid private output from landing anywhere in the checkout.
